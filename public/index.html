功能模块

共 6 个分组、17 个模块，与顶栏二级菜单一一对应

基础计算
声压级叠加计算 可用 多声源能量叠加、增量速算（差 0–20 dB 参考表）、相干叠加、背景噪声修正、频带谱叠加与距离衰减换算。 背景噪声评价 可用 A 声级 / NC / NR / RC Mark II 倍频带评价，支持 1/1 与 1/3 倍频程、多测点能量平均、房间目标值对照。 单位与换算 可用 声压级加减（含相干与非相干合成、背景噪声修正）、声压／声强／声功率级换算、距离衰减与指向性、A/B/C 计权网络换算。
材料与构件
穿孔率计算 可用 正方形 / 45° 菱形 / 矩形错排 / 等边三角形阵列的穿孔率，含反算中心距、加工校核与微穿孔板共振估算。 多孔吸声材料阻抗 可用 Delany–Bazley 模型由流阻率推算特征阻抗、表面阻抗与倍频带法向吸声系数，含 NRC、空腔增益与厚度建议。
房间声学
室内混响时间 RT60 可用 Sabine / Eyring 逐频带计算，内置 20 类常用材料吸声系数库与空气吸收修正，附房间用途推荐值判定与改进建议。 墙体隔声量 Rw / STC 可用 质量定律估算或输入实测隔声量，同时给出国标 GB/T 50121 计权隔声量 Rw 与频谱修正量 C、Ctr，以及美标 ASTM E413 的 STC，并对照 GB 50118 / GB 55038 限值判定。 厅堂与扩声音质 可用 由衰减曲线求 RT60／EDT，清晰度 C50／C80、明晰度 D50、中心时间 Ts、强度因子 G，以及房间常数、临界距离与直达+混响扩声级预测。
环境与振动
声屏障衰减计算 可用 菲涅尔数法逐频带绕射衰减（Maekawa / Kurze–Anderson），叠加声源谱给出 A 计权插入损失，附断面示意与所需高度反算。 弹簧减振（隔振效率计算书） 可用 静变形法选型计算书（运行重量→每只承载→静压缩量→固有频率→频率比→传递率→隔振效率）与频率比法含阻尼验算双路并行，附目标效率反算与传递率曲线。 环境噪声评价 可用 由实测序列求 Leq 与 L5/L10/L50/L90/L95 统计声级、昼夜等效 Ldn/Lden、NPL/TNI，NR 曲线反查，ISO 9613 户外传播与道路交通线声源预测，附 GB 3096 对照。 振动评价 可用 加速度／速度／位移振级互换（基准 10⁻⁶/10⁻⁹/10⁻¹²），ISO 2631 计权 Wb/Wc/Wd/We 与加权振级 aw，VDV 累积暴露、每日暴露限值，附 GB 10070 区域限值判定。 消声器计算 可用 阻性消声器（GB/T 50087-2013 式 6.3.1，附别洛夫式对照、高频失效折减、流速与压力损失校核）、抗性消声器（扩张室与共振腔）与阻抗复合验算（逐频带相加 → A 计权插入损失）。
心理与声品质
心理声学 / 声品质 可用 响度 phon↔sone（Stevens）、Bark 临界带映射、Zwicker 特征响度与尖锐度（DIN 45692），粗糙度／抖动度估算，PNL/Noy 总感觉噪声级与 STIPA 语言传输指数。
模拟与可听化
室内音质模拟彩图 可用 Odeon 式分布图版式：左侧三维轴测房间里铺声场彩图，右侧为指标色标标杆（色带＋数值刻度＋接收点读数）。指标含六个倍频带的相对声压级、C50、C80、D50、Ts 与 混响时间 EDT / T30 分布，可导出 PNG。 声场粒子动画 可用 把声线当作声粒子：从声源出发在房间内往复反射、逐次被界面吸收（亮度随剩余能量衰减）。2D 平面 / 3D 轴测随时切换，可调声速与拖尾，并能导出 GIF 或 MP4/WebM 动画。 声学可听化 可用 ①混响 A/B 对比：同一干信号（拍手／合成音节／粉噪／上传音频）分别卷积两个房间脉冲响应，直接试听不同混响时间下的音质差异；②隔声试听：噪声经不同隔声量构件阻隔前后的声音大小对比，给出 A 计权降低量与 Rw 参考。

背景噪声评价

输入倍频带声压级，得到 A 声级、NC、NR、RC Mark II 评价结果与房间目标值对照

输入模式

倍频带声压级输入 (dB，1/1 倍频程 16 Hz–8 kHz 共 10 带)

多测点能量平均

每行粘贴一条完整频谱的数值（当前模式对应 10 个倍频带或 29 个 1/3 倍频带，空格或逗号分隔），求各带能量平均后填入上方输入框。

A 声级
NC 噪声标准曲线
NR 噪声评价曲线
RC 房间标准曲线

房间目标值对照 (选用途，自动判定达标)

频谱与标准曲线对比

计算方法

  • A 声级：LA = 10·log₁₀ Σ 10(Lᵢ + Aᵢ)/10，Aᵢ 由 IEC 61672 解析式计算，支持任意 1/3 倍频带中心频率。
  • NC：ANSI/ASA S12.2-2019 切线插值法，逐带插值曲线指数取最大值（31.5–8000 Hz 共 9 带），控制带标出起决定作用的频带。
  • NC 低频一致性：以 NC(SIL) 曲线为基准比较 31.5/63/125/250 Hz，超出 6–9 dB 提示可能引起严重不满，>9 dB 提示很可能引起（S12.2 频谱不平衡法）。
  • NR：ISO/R 1996 切线插值法，同理取各带最大 NR 指数。
  • RC Mark II：RC = round(均值(L₅₀₀, L₁₀₀₀, L₂₀₀₀))，参考曲线为以 1 kHz 为锚点、−5 dB/倍频程的直线，16/31.5 Hz 取 max(RC+25, 55)；≤500 Hz 超 5 dB 判 R，1000–4000 Hz 超 3 dB 判 H，否则 N。
  • QAI（品质评价指数）：SD低/SD中/SD高 分别为 16–63、125–500、1000–4000 Hz 三组偏差的能量平均，QAI = max(SD) − min(SD)，数值越小频谱越均衡（≤5 dB 通常视为均衡，为经验参考）。
  • RV（振动/颤振风险）：16/31.5 Hz ≥ 65 dB 或 63 Hz ≥ 70 dB 判中等风险，≥ 75/75/80 dB 判明确风险（ANSI/ASA S12.2-2019）。
  • 1/3 倍频程：1/3 倍频程输入先按各带能量合成倍频程（每带取上下限 f/√2 ~ f·√2 内的 1/3 带求和），再按上述倍频程方法评价。
  • 多测点能量平均：逐带 L̄ = 10·log₁₀( Σ10Lᵢ/10 / n )，即功率平均（非算术平均）。
  • 目标值对照：房间目标范围引自 ASHRAE Handbook HVAC Applications 常用 NC 推荐值，RC 取等价目标，判定以 NC 为主、RC 交叉参考。

单位与换算

声压级能量加减、声压 / 声强 / 声功率互转、点 / 线 / 面声源距离衰减，以及 A / C / Z 计权网络速查

声级相加 / 相减（背景修正）

粘贴若干声压级（空格 / 逗号分隔）求能量总和与增加值；或填写「总量」与「部分量（如背景）」求扣除后剩余。

单位换算

四个量任选其一，其余自动算出（声压 p₀=20 µPa，声强 I₀=10⁻¹² W/m²，声功率 W₀=10⁻¹² W；平面波下 I = p²/(ρc)，ρc≈400 Pa·s/m）。

距离衰减 / 点声源声压级

A / C / Z 计权网络（相对 1000 Hz）

各中心频率处的计权衰减值（dB）。A 计权对应人耳等响曲线，C 计权近线性，Z 计权（零计权）为平直。

环境声学评价

等效声级 · 统计声级 · 昼夜声级 Ldn/Lden · 噪声污染级 · 噪声评价数 NR · 户外声传播 · 交通噪声

等效声级 Leq 与统计声级

粘贴等间隔采样声级（空格 / 逗号分隔），求等效连续声级 Leq 与 L5 / L10 / L50 / L90 / L95（L_N 表示被超过 N% 的时间）。

昼夜等效声级 Ldn / 昼夜计权声级 Lden

Ldn：昼（默认 07–22，15h）无加成，夜（22–07，9h）+10 dB；Lden：昼 12h、傍晚（+5）3h、夜（+10）9h。

噪声污染级 NPL / 交通噪声指数 TNI

NPL = Leq + (L10 − L90)（或 Leq + 2.56σ）；TNI = 4(L10 − L90) + L90 − 30。

噪声评价数 NR

输入各倍频带声压级（dB），取「带值 − 该带 NR 偏移」的最大值并取整（NR 数对应 1000 Hz 处曲线值）。

户外声传播（ISO 9613-2，A 计权）

输入各倍频带声功率级 L_W（dB），计算自由场接收点 A 声级。含几何发散、ISO 9613-1 大气吸收与（简化）地面效应。

倍频带 (Hz)L_WA_divA_atmA_grL_pL_pA

公路交通噪声（线声源近似）

无限长线声源模型：L_p = L_WL − 10log₁₀(2πr) − 大气吸收 − 地面。车流越大、车速越高、距离越近越吵。

心理声学 / 声品质

响度 · 尖锐度 · 粗糙度 / 抖动度 · 感觉噪声级 PNL · 语言传输指数 STIPA

响度级 ↔ 响度 换算

响度级 L_N（phon）与响度 N（sone）精确换算：N = 2^((L_N−40)/10)。1 sone = 40 phon。

总响度估算 / 尖锐度（倍频带，工程近似）

输入各倍频带声压级（dB），估算总响度（sones，仅供参考）与尖锐度（acum）。高频占比越高越尖锐。

粗糙度 / 抖动度（调制感知，经典模型）

粗糙度峰值在调制频率≈70Hz，抖动度峰值≈4Hz。需给出调制频率、调制深度(0~1)与整体响度 N（sones）。

感觉噪声级 PNL（倍频带，简化）

基于 1/1 倍频带声压级估算感觉噪声级 PNL（dB）。低/高频比中频更"吵"，低带贡献更大。

语言传输指数 STIPA / STI

输入 14 个调制带（0.63~12.5Hz）的调制传输 MTF（0~1，逗号/空格分隔），计算 STI 并评级。MTF=1 传输完美，0 完全丢失。

振动评价

振动级换算 · ISO 2631 频率计权与计权加速度 aw · VDV · 暴露限值 · GB 10070 环境振动标准

振动级换算与 a / v / d 互算

参考值：加速度 a₀=10⁻⁶ m/s²、速度 v₀=10⁻⁹ m/s、位移 d₀=10⁻¹² m。给定频率可互算加速度/速度/位移。

计权振动级与计权加速度 aw（倍频带，近似）

输入各倍频带加速度级（dB），按 ISO 2631-1 频率计权（Wb 建筑物/连续、Wc 冲击、Wd 车间、We 船舶）求计权总振动级与计权 RMS 加速度 aw。

人体暴露评价（ISO 2631-1）

由计权 RMS 加速度 aw（m/s²）与每日暴露时长(h)评价。8h 行动值 0.5、暴露限值 1.15 m/s²；按 √(t) 缩放。

振动剂量值 VDV

VDV = (∫ a_w⁴ dt)^(1/4)，稳态近似 VDV = a_rms·Cf·T^¼（T 秒）。常用限值：8h 行动值 8.5、暴露限值 17（m/s^1.75）。

GB 10070 城市区域环境振动标准

铅垂向 Z 计权振动级（dB，快档）对照标准限值。昼/夜分别判定达标。

厅堂与扩声音质

混响/早期衰减(RT60/EDT) · 清晰度(C50/C80) · 定义度(D50) · 中心时间(Ts) · 强度因子(G) · 扩声系统预测

混响时间 RT60 与早期衰减 EDT

由能量衰减曲线不同区间的时间(s)外推：RT60 = 6·T₁₀ = 3·T₂₀ = 2·T₃₀；EDT = 6·T₁₀（仅前 10dB 斜率）。

清晰度 C50 / C80 与定义度 D50

输入脉冲响应积分"线性能量"（可带相对量纲）：E₅₀(0–50ms)、E₈₀(0–80ms)、E_tot（总）。C50=10lg(E₅₀/(E_tot−E₅₀))，C80=10lg(E₈₀/(E_tot−E₈₀))，D50=E₅₀/E_tot×100%。

中心时间 Ts

Ts = Σ t·E(t) / Σ E(t)。输入逐点"时间(ms)"与对应"能量(dB)"，逗号/空格分隔（成对）。

强度因子 G

G = Lp − Lw + 10lg(4πr²)（点声源，r 米）。反映声场"响度"相对于参考距离的增益(或衰减)。

扩声系统声场预测

给定声源 Lw、指向性 Q、听众距离 r，以及房间表面积 S 与平均吸声系数 α：求房间常数 R、临界距离 r_c、该处声压级 Lp（直达+混响）。

室内音质模拟彩图

矩形房间几何声学光线追踪，输出 Odeon / CATT 版式的声场彩图：左侧三维轴测模型（地面铺指标分布），右侧指标色标标杆（色带 + 刻度 + 接收点读数）。支持六个倍频带 + 中频均值，指标含混响时间 EDT / T30，彩图可导出 PNG。

房间与吸声

输入房间长（x 向）、宽（y 向）与层高（米）；六个界面统一取吸声系数 α（可按材料取中频值）；可另加一道竖向内隔墙。

方法说明与限制

  • 本模块基于几何声学（镜像声源 Allen & Berkley + 光线/声锥追踪 Kuttruff 一类公开方法），与 Odeon / CATT / Raynoise 同属一类方法体系，为自研实现，非任何商业软件的复刻。
  • 声线终止采用俄罗斯轮盘赌（无偏蒙特卡洛），反射按散射系数 s 在镜面反射与朗伯漫射之间随机选择——纯镜面反射的矩形房间是非遍历的，无法形成扩散声场，必须引入漫射才能得到合理的混响衰减。
  • 结果为方案比选级估算：忽略边缘衍射、家具散射细节与低频波动效应，不可替代授权软件做正式验收。
  • 彩图版式：左侧房间轴测模型（地面铺该指标分布彩图，蓝→青→绿→黄→红 由低到高）；右侧指标色标标杆，色带旁标注整齐刻度数值（首末以 ≥ / ≤ 表示截断），蓝色三角指示接收点读数。
  • 颜色按分位区间归一化（剔除极少数离群格），因此颜色差 ≠ 等量数值差，务必以右侧色标实际数值为准。Ts 为反向色标（越小越清晰，显示为越冷）。
  • T30 由 −5 ~ −35 dB 段外推、EDT 由前 10 dB 外推；当衰减不足 35 dB 时自动降级为 −5 ~ −25 dB / −1 ~ −15 dB 并标注。

板材开孔估算 (按当前穿孔率)

计算方法

  • 基本关系：穿孔率 σ = 单孔面积 / 单元面积 × 100%，单孔面积 = πd²/4；孔径 d 与中心距（孔心距）单位一致即可（本页统一用 mm）。
  • 正方形对称阵列：单元面积 P²（一个孔对应 P × P 的方格），σ = πd² / (4P²) × 100%。
  • 45° 菱形错排：隔行错开半个孔距、行距 P/2，单元面积 P²/2，σ = πd² / (2P²) × 100%（沿用 E5-lab/AC_Calc 参考实现的约定）。
  • 矩形非等边错排：横向中心距 P1、纵向行距 P2/2，单元面积 P1·P2/2，σ = πd² / (2·P1·P2) × 100%。
  • 等边三角形错排（六方）：行距 (√3/2)P，单元面积 (√3/2)P²，σ = πd² / (2√3·P²) × 100%。这是等边三角阵列的几何精确解，同孔径同孔距下穿孔率高于正方形阵列约 15.5%。
  • 反算：由 σ 反解中心距，例如正方形阵列 P = √(πd² / (4σ))（σ 为分数），矩形错排需固定 P2 后解 P1。
  • 加工校核：孔间剩余壁厚 = 中心距 − 孔径，小于 0.8 mm 时冲孔/钻孔易变形；穿孔率 > 30% 时板面强度需另行校核。
  • 微穿孔板共振：f₀ = c/(2π)·√(σ/(t′·D))，t′ = t + 0.85d 为计入端部修正的有效板厚，D 为空腔深度；用于判断吸声峰值大致落点，配合 1/4 波长关系可做空腔深度初选。实际结构建议以阻抗管/混响室实测为准。
  • 常用区间：微穿孔板 σ 约 0.5%–3%（d 0.5–2 mm）；常规穿孔吸声板 σ 约 3%–15%；σ > 30% 接近全透声，吸声取决于后置材料。

逐带明细 (两标准轮廓线与偏差)

计算方法

  • 质量定律：R = 20·lg(m·f) − 48（m 为面密度 kg/m²，f 为频率 Hz），适用于单层密实匀质构件在吻合频率以下的扩散场隔声估算，精度约 ±3 dB。
  • 面密度：由材料密度与厚度换算（m = ρ·t）；也可直接在界面上手改，用于已知面密度的复合构件。
  • 吻合频率：f_c = c₀²/(1.8·c_L·t)，c_L 为材料纵波声速。在 f_c 附近隔声量会出现明显谷值，质量定律不再适用，实测值往往显著低于质量定律预测值。
  • 计权隔声量 Rw（GB/T 50121-2005）：在 100–3150 Hz 共 16 个 1/3 倍频带（或 125–2000 Hz 共 5 个倍频带）上，把表 3.1.2 的空气声隔声基准曲线 Ki（500 Hz 处为 0 dB）逐 dB 平移，取满足「不利偏差之和 ≤ 32.0 dB（1/3 倍频程）／≤ 10.0 dB（倍频程）」的最大值，即为 Rw；国标采用 ISO 717-1:1996 方法，不设 8 dB 单带限值。
  • 频谱修正量 C / Ctr（GB/T 50121-2005 式 3.4.1）：Cj = −10·lg Σ10^((Lij − Xi)/10) − Xw，其中 Lij 为表 3.1.3 的 A 计权频谱（总级归一化到 0 dB）。C 对应频谱 1（粉红噪声，以社会生活噪声为代表，中高频为主），Ctr 对应频谱 2（交通噪声，中低频为主）。结果按 GB 表述为 Rw(C; Ctr) = 45(−1; −5) dB，并给出 Rw+C、Rw+Ctr。
  • 隔声等级 STC（ASTM E413）：以 500 Hz 处为 0 dB、向低频每倍频程 −5 dB 的标准轮廓线，在 125–4000 Hz 共 16 个 1/3 倍频带上逐 dB 平移，取满足「缺量之和 ≤ 32 dB 且任一频带缺量 ≤ 8 dB」的最大轮廓值。
  • 两标准差异：频带范围不同（GB 100–3150 Hz，ASTM 125–4000 Hz），且 ASTM 多一条 8 dB 单带限值，因此同一构件常有 1–2 dB 差别；对低频敏感的构件（轻质墙、玻璃），国标因含 100 Hz 频带而更严格。工程上国内设计验收应以 Rw+C / Rw+Ctr 表述。
  • 国标限值对照：内置 GB 50118-2010《民用建筑隔声设计规范》与 GB 55038-2025《住宅项目规范》中构件类的空气声隔声要求，可直接判定是否达标并给出余量。注意：GB 55038-2025 对住宅分户构件的强制性指标为现场「计权标准化声压级差 DnT,w+C」（卧室分户墙/楼板 ≥ 50 dB），属房间之间的现场量，受侧向传声影响，一般比构件实验室 Rw+C 低 2–5 dB，不能直接等同。
  • 双层构件：在总面密度质量定律基础上加 3 dB（两层解耦）并叠加空气层增益 12·lg(1 + D/50)，为常用经验估算式，用于方案比较；实际双层墙还需考虑层间声桥、空腔填充与板缝密封。
  • 注意：本模块评价空气声隔声，对结构传声与撞击声（楼板 Ln,w）不作评价；轨道交通、风机等以低频为主的噪声源，建议结合噪声评价与声屏障模块一并分析。

1 几何与声源参数

2 断面示意 (按当前尺寸等比绘制)

A 计权插入损失 ΔL
—dB

倍频带明细

所需屏障高度反算

计算方法

  • 几何：D 为声源到接收点的直线距离，A 为声源到屏障顶的距离，B 为屏障顶到接收点的距离，程差 δ = A + B − D（即绕射相对直达的额外路程）。
  • 菲涅尔数：N = 2δ/λ = 2fδ/c₀。N 越大，绕射衰减越多；同一几何下高频衰减大于低频，因此声屏障对低频噪声效果有限。
  • 绕射衰减：Maekawa ΔL = 5 + 20·lg(√(2πN)/tanh√(2πN))；Kurze–Anderson ΔL = 10·lg(3 + 20N)，后者在小 N 时更平滑，默认使用。
  • A 计权插入损失：将各倍频带声源级加 A 计权后按能量叠加，分别计算屏障前后的总声级之差，得到与听感相关的降噪量。
  • 实用上限：实际工程中因侧向绕射、屏障透射漏声、声源指向性与地面效应，插入损失通常在 10–20 dB 以内。本页默认按 24 dB 截断，可按项目经验调整。
  • 视线校核：若屏障顶低于声源—接收点视线高度，绕射衰减可忽略（屏障无效），本页会直接提示。
  • 所需高度反算：在给定水平距离与声源谱下逐 0.05 m 试算屏障高度，返回首个满足目标插入损失的高度。
  • 注意：本模型只计绕射，不含地面声反射、气象条件（风速/温度梯度）与多屏障叠加，长距离户外预测请结合 GB/T 17247.2 等标准方法。

为什么 dB 不能直接相加

  • 能量叠加：声压级是对数量，叠加要先把各声级换算为声压平方（能量）再相加，L = 10·lg Σ10^(Li/10)。
  • 两个等声级：叠加只增加 3 dB；三个增加 4.8 dB；四个增加 6 dB（即声级相同、数量加倍只多 3 dB）。
  • 增量法：两声级相差越大，弱的一方贡献越小。相差 10 dB 时只增加 0.4 dB，相差 20 dB 时几乎可忽略。
  • 相干叠加：同频且相位固定时声压按矢量相加，等强同相可增加 6 dB；反相则相互抵消，这是主动降噪的原理。
  • 结论：治理噪声时，总是先降「最强的那个声源」最有效；当总级中有多个等强声源时，逐个降低的收益会明显变小。

背景噪声修正 (从实测总级中扣除背景)

声压级 ↔ 声压

距离衰减 (自由场)

声功率级 ↔ 声压级 (点声源)

计算方法

  • 能量叠加（不相干声源）：L = 10·lg Σ10^(Li/10)。两台互不相干的设备（不同频率成分、随机相位）按声压平方相加，不能把 dB 直接相加。
  • 增量法：设两声级差 Δ = |L₁ − L₂|，则增加量 ΔL = 10·lg(1 + 10^(−Δ/10))。Δ = 0 → +3.0 dB，Δ = 3 → +1.8 dB，Δ = 10 → +0.4 dB，Δ ≥ 15 → 可忽略。
  • 相干叠加：同频且有固定相位差 φ 时，L = 10·lg[10^(L₁/10) + 10^(L₂/10) + 2·10^((L₁+L₂)/20)·cos φ]。φ = 0 同相（等强时 +6 dB），φ = 90° 退化为能量叠加，φ = 180° 反相（等强时完全抵消）。
  • 多声源叠加：各声源按能量相加；某声源的能量占比 = 10^(Li/10)·n / Σ，撤除该声源后总级的下降量反映其重要性 —— 占比小于 10%（即撤除后下降不足 0.5 dB）的声源基本可忽略。
  • 达标反算：把目标值换算为能量后减去其余声源的能量，得到该声源允许的剩余能量，再反算需降低的 dB；若其余声源合计已超过目标，则仅降此声源无法达标。
  • 背景噪声修正：L源 = 10·lg(10^(L总/10) − 10^(L背景/10))。实测总级与背景级相差 < 3 dB 时修正结果偏差过大，应避免；相差 ≥ 10 dB 时背景影响可忽略。工程上常用取整修正表（差 3 → 扣 3 dB，差 4–5 → 扣 2 dB，差 6–9 → 扣 1 dB，≥ 10 → 不修正）。
  • 距离衰减：点声源（自由场）按 6 dB/倍距（ΔL = 20·lg(r₂/r₁)）；线声源（如长车流、管道）按 3 dB/倍距（ΔL = 10·lg(r₂/r₁)）。实测中因地面反射与空气吸收，衰减量通常介于两者之间。
  • 声功率级换算：点声源 Lp = Lw + 10·lg(Q/4π) − 20·lg r，Q = 1（自由场，−11 dB）、2（半自由场，−8 dB）、4（墙角，−5 dB）、8（三面交角，−2 dB）。
  • 注意：本模块为能量（功率）意义上的叠加，适用于稳态、互不相干的声源；若声源同频且相位关系稳定（如单一低频纯音、驻波场），应改用相干叠加。

频率比判定准则与效率等级

计算方法

  • 方法一 · 静变形法（静态压缩量法）：由设备运行重量与所选减振器的竖向刚度求出静态压缩量 δ，再由 δ 求系统固有频率 f₀ = 4.9823·√(K_D/W) ≈ 15.76/√δ（δ 取 mm；橡胶类需再乘 √d，因动、静刚度比 d 大于 1）。这是选型时的正算流程，也是减振器样本最常用的表达方式。
  • 方法二 · 频率比法（含阻尼传递率）：直接按频率比 z = f/f₀ 与阻尼比 D 计算力传递率 T = √{[1+(2Dz)²] / [(1−z²)²+(2Dz)²]}；D = 0 时退化为标准的无阻尼简化式 T = |1/(1−z²)|。
  • 隔振效率：η = (1 − T) × 100%；与分贝表示的对应关系为 ΔL = 20·lg(1/T)，例如 T = 0.1 相当于降低 20 dB（效率 90%），T = 0.01 相当于降低 40 dB（效率 99%）。
  • 频率比准则：《噪声与振动控制工程技术导则》规定频率比宜取 2.5 ~ 4，禁止小于 1.4。z < 1 时传递率大于 1，减振器反而放大振动；z = √2 是隔振与放大的临界点。
  • 阻尼的两面性：阻尼能显著压低共振区的放大倍数（峰值 T = √(1+4D²)/(2D)，D = 0.05 时约 10 倍），但在 z > √2 的高频段会使传递率略高于无阻尼值，因此实际效率会比简化式算出的略低 —— 这也是设计方案应留一定余量的原因。
  • 参数方向：刚度越小（弹簧越软）→ 静态压缩量越大 → 固有频率越低 → 频率比与效率越高。但压缩量过大会带来弹簧高度、稳定性与设备晃动问题，常用弹簧减振器的静态压缩量多在 10 ~ 50 mm。
  • 选型要点：每只减振器的实际荷载宜为样本额定荷载的 50% ~ 100%（最佳荷载略大于实际承载），既保证刚度假定成立，又避免长期低荷载导致疲劳；设备重心与减振器刚度中心应在同一铅垂线上，重量分布不均时按实际支点反力分配。
  • 注意：本模块按单频稳态简谐激励、线性弹簧-质量系统计算；回转型设备除旋转频率 f = n/60 外还可能存在 2f 等谐波（不平衡、对中不良），必要时应按最高谐波校核。冲击、瞬态激励与多层隔振体系需另行分析。
