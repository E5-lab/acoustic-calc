计算方法

  • A 声级：LA = 10·log₁₀ Σ 10(Lᵢ + Aᵢ)/10，Aᵢ 由 IEC 61672 解析式计算，支持任意 1/3 倍频带中心频率。
  • NC：ANSI/ASA S12.2-2019 切线插值法，逐带插值曲线指数取最大值（31.5–8000 Hz 共 9 带），控制带标出起决定作用的频带。
  • NC 低频一致性：以 NC(SIL) 曲线为基准比较 31.5/63/125/250 Hz，超出 6–9 dB 提示可能引起严重不满，>9 dB 提示很可能引起（S12.2 频谱不平衡法）。
  • NR：ISO/R 1996 切线插值法，同理取各带最大 NR 指数。
  • RC Mark II：RC = round(均值(L₅₀₀, L₁₀₀₀, L₂₀₀₀))，参考曲线为以 1 kHz 为锚点、−5 dB/倍频程的直线，16/31.5 Hz 取 max(RC+25, 55)；≤500 Hz 超 5 dB 判 R，1000–4000 Hz 超 3 dB 判 H，否则 N。
  • QAI（品质评价指数）：SD低/SD中/SD高 分别为 16–63、125–500、1000–4000 Hz 三组偏差的能量平均，QAI = max(SD) − min(SD)，数值越小频谱越均衡（≤5 dB 通常视为均衡，为经验参考）。
  • RV（振动/颤振风险）：16/31.5 Hz ≥ 65 dB 或 63 Hz ≥ 70 dB 判中等风险，≥ 75/75/80 dB 判明确风险（ANSI/ASA S12.2-2019）。
  • 1/3 倍频程：1/3 倍频程输入先按各带能量合成倍频程（每带取上下限 f/√2 ~ f·√2 内的 1/3 带求和），再按上述倍频程方法评价。
  • 多测点能量平均：逐带 L̄ = 10·log₁₀( Σ10Lᵢ/10 / n )，即功率平均（非算术平均）。
  • 目标值对照：房间目标范围引自 ASHRAE Handbook HVAC Applications 常用 NC 推荐值，RC 取等价目标，判定以 NC 为主、RC 交叉参考。

声速

简化式 c = 331.4 + 0.6·T；开方式 c = 331.3·√(TK/273.15)；含湿式按干空气／水蒸气混合物的 γ 与摩尔质量求解。纯水采用 UNESCO / Marczak 多项式（0~40 ℃）。

λ = c/f。同时给出周期、波数、λ/2 与 λ/4（房间轴向模态与 1/4 波长吸声结构的起效尺度），以及常用倍频带的波长速查表。

自由场声强与平方反比

点声源自由场 I = Q·P/(4πr²)，声强级 LI = 10·lg(I/I₀)，I₀ = 10⁻¹² W/m²；每倍距离衰减 6 dB。可填声功率 W 或声功率级 LW。

特性声阻抗与界面反射

Z = ρc。垂直入射 Rp = (Z₂−Z₁)/(Z₂+Z₁)、τ = 4Z₁Z₂/(Z₁+Z₂)²；斜入射按法向声阻抗 Z/cosθ，折射角由 Snell 定律求，超过临界角即全反射。

比值 ↔ 分贝

功率量（声功率 / 声强）用 10·lg，场量（声压 / 电压）用 20·lg。两个方向都可算，3 dB 与 6 dB、「10 倍」与「20 dB」不再记混。

乐音：频率 ↔ 音名 ↔ 音分

十二平均律，A4 = 440 Hz。f = 440·2^((n−69)/12)，音分 = 1200·log₂(f/f₀)。拍频 = |f₁ − f₂|，20 Hz 以内可听为抖动。

管与弦共振

开管 fₙ = n·c/(2Leff)（含全部谐波）；闭管 fₙ = (2n−1)·c/(4Leff)（仅奇次）；弦 fₙ = n/(2L)·√(T/μ)。管口修正按每端 0.6r 计。

多普勒效应

f′ = f·(c + vo)/(c − vs)。声源向观察者运动取 vs > 0，观察者向声源运动取 vo > 0；vs ≥ c 时形成激波。

心理声学 / 声品质

响度级 ↔ 响度 换算

响度级 L_N（phon）与响度 N（sone）精确换算：N = 2^((L_N−40)/10)。1 sone = 40 phon。

总响度估算 / 尖锐度（倍频带，工程近似）

输入各倍频带声压级（dB），估算总响度（sones）与尖锐度（acum）。高频占比越高越尖锐。简化模型：总响度按各带 phon→sone 直接求和，未做临界带掩蔽与响度合成；尖锐度未做临界带归一（完整方法见 Zwicker / DIN 45692），结果仅供工程参考。

粗糙度 / 抖动度（调制感知，经典模型）

粗糙度峰值在调制频率≈70Hz，抖动度峰值≈4Hz。需给出调制频率、调制深度(0~1)与整体响度 N（sones）。经验近似式（简化模型），非完整 Zwicker 调制感知理论。

感觉噪声级 PNL（倍频带，简化）

基于 1/1 倍频带声压级估算感觉噪声级 PNL（dB）。低/高频比中频更"吵"，低带贡献更大。简化模型：1/1 倍频带近似（完整 PNL 用 1/3 倍频带，纯音修正得 PNLT），供工程参考。

混响时间 RT60 与早期衰减 EDT

由能量衰减曲线不同区间的时间(s)外推：RT60 = 6·T₁₀ = 3·T₂₀ = 2·T₃₀；EDT = 6·T₁₀（仅前 10dB 斜率）。

清晰度 C50 / C80 与定义度 D50

输入脉冲响应积分"线性能量"（可带相对量纲）：E₅₀(0–50ms)、E₈₀(0–80ms)、E_tot（总）。C50=10lg(E₅₀/(E_tot−E₅₀))，C80=10lg(E₈₀/(E_tot−E₈₀))，D50=E₅₀/E_tot×100%。

中心时间 Ts

Ts = Σ t·E(t) / Σ E(t)。输入逐点"时间(ms)"与对应"能量(dB)"，逗号/空格分隔（成对）。

强度因子 G

G = Lp − Lw + 10lg(4πr²)（点声源，r 米）。反映声场"响度"相对于参考距离的增益(或衰减)。

计算方法

  • 基本关系：穿孔率 σ = 单孔面积 / 单元面积 × 100%，单孔面积 = πd²/4；孔径 d 与中心距（孔心距）单位一致即可（本页统一用 mm）。
  • 正方形对称阵列：单元面积 P²（一个孔对应 P × P 的方格），σ = πd² / (4P²) × 100%。
  • 45° 菱形错排：隔行错开半个孔距、行距 P/2，单元面积 P²/2，σ = πd² / (2P²) × 100%（沿用 E5-lab/AC_Calc 参考实现的约定）。
  • 矩形非等边错排：横向中心距 P1、纵向行距 P2/2，单元面积 P1·P2/2，σ = πd² / (2·P1·P2) × 100%。
  • 等边三角形错排（六方）：行距 (√3/2)P，单元面积 (√3/2)P²，σ = πd² / (2√3·P²) × 100%。这是等边三角阵列的几何精确解，同孔径同孔距下穿孔率高于正方形阵列约 15.5%。
  • 反算：由 σ 反解中心距，例如正方形阵列 P = √(πd² / (4σ))（σ 为分数），矩形错排需固定 P2 后解 P1。
  • 加工校核：孔间剩余壁厚 = 中心距 − 孔径，小于 0.8 mm 时冲孔/钻孔易变形；穿孔率 > 30% 时板面强度需另行校核。
  • 微穿孔板共振：f₀ = c/(2π)·√(σ/(t′·D))，t′ = t + 0.85d 为计入端部修正的有效板厚，D 为空腔深度；用于判断吸声峰值大致落点，配合 1/4 波长关系可做空腔深度初选。实际结构建议以阻抗管/混响室实测为准。
  • 常用区间：微穿孔板 σ 约 0.5%–3%（d 0.5–2 mm）；常规穿孔吸声板 σ 约 3%–15%；σ > 30% 接近全透声，吸声取决于后置材料。

  • 计权隔声量 Rw（GB/T 50121-2005）：在 100–3150 Hz 共 16 个 1/3 倍频带（或 125–2000 Hz 共 5 个倍频带）上，把表 3.1.2 的空气声隔声基准曲线 Ki（500 Hz 处为 0 dB）逐 dB 平移，取满足「不利偏差之和 ≤ 32.0 dB（1/3 倍频程）／≤ 10.0 dB（倍频程）」的最大值，即为 Rw；国标采用 ISO 717-1:1996 方法，不设 8 dB 单带限值。
  • 频谱修正量 C / Ctr（GB/T 50121-2005 式 3.4.1）：Cj = −10·lg Σ10^((Lij − Xi)/10) − Xw，其中 Lij 为表 3.1.3 的 A 计权频谱（总级归一化到 0 dB）。C 对应频谱 1（粉红噪声，以社会生活噪声为代表，中高频为主），Ctr 对应频谱 2（交通噪声，中低频为主）。结果按 GB 表述为 Rw(C; Ctr) = 45(−1; −5) dB，并给出 Rw+C、Rw+Ctr。
  • 隔声等级 STC（ASTM E413）：以 500 Hz 处为 0 dB、向低频每倍频程 −5 dB 的标准轮廓线，在 125–4000 Hz 共 16 个 1/3 倍频带上逐 dB 平移，取满足「缺量之和 ≤ 32 dB 且任一频带缺量 ≤ 8 dB」的最大轮廓值。

  • 国标限值对照：内置 GB 50118-2010《民用建筑隔声设计规范》与 GB 55038-2025《住宅项目规范》中构件类的空气声隔声要求，可直接判定是否达标并给出余量。注意：GB 55038-2025 对住宅分户构件的强制性指标为现场「计权标准化声压级差 DnT,w+C」（卧室分户墙/楼板 ≥ 50 dB），属房间之间的现场量，受侧向传声影响，一般比构件实验室 Rw+C 低 2–5 dB，不能直接等同。

为什么 dB 不能直接相加

  • 能量叠加：声压级是对数量，叠加要先把各声级换算为声压平方（能量）再相加，L = 10·lg Σ10^(Li/10)。
  • 两个等声级：叠加只增加 3 dB；三个增加 4.8 dB；四个增加 6 dB（即声级相同、数量加倍只多 3 dB）。
  • 增量法：两声级相差越大，弱的一方贡献越小。相差 10 dB 时只增加 0.4 dB，相差 20 dB 时几乎可忽略。
  • 相干叠加：同频且相位固定时声压按矢量相加，等强同相可增加 6 dB；反相则相互抵消，这是主动降噪的原理。
  • 结论：治理噪声时，总是先降「最强的那个声源」最有效；当总级中有多个等强声源时，逐个降低的收益会明显变小。

计算方法

  • 能量叠加（不相干声源）：L = 10·lg Σ10^(Li/10)。两台互不相干的设备（不同频率成分、随机相位）按声压平方相加，不能把 dB 直接相加。
  • 增量法：设两声级差 Δ = |L₁ − L₂|，则增加量 ΔL = 10·lg(1 + 10^(−Δ/10))。Δ = 0 → +3.0 dB，Δ = 3 → +1.8 dB，Δ = 10 → +0.4 dB，Δ ≥ 15 → 可忽略。
  • 相干叠加：同频且有固定相位差 φ 时，L = 10·lg[10^(L₁/10) + 10^(L₂/10) + 2·10^((L₁+L₂)/20)·cos φ]。φ = 0 同相（等强时 +6 dB），φ = 90° 退化为能量叠加，φ = 180° 反相（等强时完全抵消）。
  • 多声源叠加：各声源按能量相加；某声源的能量占比 = 10^(Li/10)·n / Σ，撤除该声源后总级的下降量反映其重要性 —— 占比小于 10%（即撤除后下降不足 0.5 dB）的声源基本可忽略。
  • 达标反算：把目标值换算为能量后减去其余声源的能量，得到该声源允许的剩余能量，再反算需降低的 dB；若其余声源合计已超过目标，则仅降此声源无法达标。
  • 背景噪声修正：L源 = 10·lg(10^(L总/10) − 10^(L背景/10))。实测总级与背景级相差 < 3 dB 时修正结果偏差过大，应避免；相差 ≥ 10 dB 时背景影响可忽略。工程上常用取整修正表（差 3 → 扣 3 dB，差 4–5 → 扣 2 dB，差 6–9 → 扣 1 dB，≥ 10 → 不修正）。
  • 距离衰减：点声源（自由场）按 6 dB/倍距（ΔL = 20·lg(r₂/r₁)）；线声源（如长车流、管道）按 3 dB/倍距（ΔL = 10·lg(r₂/r₁)）。实测中因地面反射与空气吸收，衰减量通常介于两者之间。
  • 声功率级换算：点声源 Lp = Lw + 10·lg(Q/4π) − 20·lg r，Q = 1（自由场，−11 dB）、2（半自由场，−8 dB）、4（墙角，−5 dB）、8（三面交角，−2 dB）。
  • 注意：本模块为能量（功率）意义上的叠加，适用于稳态、互不相干的声源；若声源同频且相位关系稳定（如单一低频纯音、驻波场），应改用相干叠加。

频率比判定准则与效率等级

计算方法

  • 方法一 · 静变形法（静态压缩量法）：由设备运行重量与所选减振器的竖向刚度求出静态压缩量 δ，再由 δ 求系统固有频率 f₀ = 4.9823·√(K_D/W) ≈ 15.76/√δ（δ 取 mm；橡胶类需再乘 √d，因动、静刚度比 d 大于 1）。这是选型时的正算流程，也是减振器样本最常用的表达方式。
  • 方法二 · 频率比法（含阻尼传递率）：直接按频率比 z = f/f₀ 与阻尼比 D 计算力传递率 T = √{[1+(2Dz)²] / [(1−z²)²+(2Dz)²]}；D = 0 时退化为标准的无阻尼简化式 T = |1/(1−z²)|。
  • 隔振效率：η = (1 − T) × 100%；与分贝表示的对应关系为 ΔL = 20·lg(1/T)，例如 T = 0.1 相当于降低 20 dB（效率 90%），T = 0.01 相当于降低 40 dB（效率 99%）。
  • 频率比准则：《噪声与振动控制工程技术导则》规定频率比宜取 2.5 ~ 4，禁止小于 1.4。z < 1 时传递率大于 1，减振器反而放大振动；z = √2 是隔振与放大的临界点。
  • 阻尼的两面性：阻尼能显著压低共振区的放大倍数（峰值 T = √(1+4D²)/(2D)，D = 0.05 时约 10 倍），但在 z > √2 的高频段会使传递率略高于无阻尼值，因此实际效率会比简化式算出的略低 —— 这也是设计方案应留一定余量的原因。
  • 参数方向：刚度越小（弹簧越软）→ 静态压缩量越大 → 固有频率越低 → 频率比与效率越高。但压缩量过大会带来弹簧高度、稳定性与设备晃动问题，常用弹簧减振器的静态压缩量多在 10 ~ 50 mm。
  • 选型要点：每只减振器的实际荷载宜为样本额定荷载的 50% ~ 100%（最佳荷载略大于实际承载），既保证刚度假定成立，又避免长期低荷载导致疲劳；设备重心与减振器刚度中心应在同一铅垂线上，重量分布不均时按实际支点反力分配。
  • 注意：本模块按单频稳态简谐激励、线性弹簧-质量系统计算；回转型设备除旋转频率 f = n/60 外还可能存在 2f 等谐波（不平衡、对中不良），必要时应按最高谐波校核。冲击、瞬态激励与多层隔振体系需另行分析。

dBV 以 1 V 为 0 dB，dBu 以 √0.6 = 0.7746 V 为 0 dB，两者相差 2.2185 dB；dBm 是功率量（1 mW 基准），必须指定负载才有确定电压；dBFS 需先选定满刻度基准。

灵敏度：1 W/1 m ↔ 2.83 V/1 m

SPL(2.83 V) = SPL(1 W) + 10·lg(8/Z)。8 Ω 时两套标注数值相同；4 Ω 音箱用 2.83 V 标注会比 1 W 标注「好看」3 dB。比较不同厂家灵敏度时务必先看是哪种标注。

串并联阻抗与 SPL 增减

恒压功放模型：并联每只都拿到满电压，总功率 ×N（每加倍 +3 dB）；串联每只只拿到 U/N，总功率 ÷N（每加倍 −3 dB）；串并联可在总阻抗与声压之间折中。

功放功率 → 最大声压级

SPL(r) = SPL1W/1m + 10·lg(P) − 20·lg(r)。每倍距离 −6 dB、功率每加倍 +3 dB。多只非相干叠加 +10·lg N，理想同相相干叠加 +20·lg N。

功放选型：目标声压反算功率

先由目标 SPL 与距离反算 1 m 处所需声压级，再换算每只连续功率；叠加波峰因数得峰值功率，叠加余量得建议功放功率。功放长期功率不足会削波失真，比功率不足本身更伤高音单元。

线材电阻与阻尼系数

R = ρ·L/A（回路按往返两根计）。阻尼系数 DF = Z负载 / (Z功放内阻 + R回路)；线损 = 20·lg(Z/(Z+Rs))。DF ≥ 50 优秀、20~50 良好、10~20 可接受、<10 时低频明显拖尾。

允许线长反算

给定线损上限（工程常用 0.5 dB）与阻尼系数下限（常用 20），两条约束取更严格者，反算允许的回路电阻与单程线长，并给出各规格对照。

IEC 60268-5 阻抗校核与功放匹配

IEC 60268-5：扬声器阻抗模的最小值不得低于标称值的 80 %。实际阻抗随频率大幅起伏（谐振峰可达标称的 3~5 倍），应以实测曲线最低点为准。工程惯例：功放额定功率取音箱连续功率的 1.5~2 倍。

频谱分析与计权

把测得的窄带数据整理成能下结论的形式：归并到倍频程、施加 A/C/Z 计权、对照 NR / NC 曲线评级。全部按能量运算，归并前后总能量守恒。

频带归并

粘贴任意频率点（窄带 FFT、1/3 倍频程、或零散读数），按能量求和归并到 1/1 或 1/3 倍频程。每行一条「频率 声压级」，可用空格、逗号、制表符或分号分隔，# 开头为注释。

柱状为未计权频带级，橙线为 A 计权后。

NR / NC 评级

填入 1/1 倍频程声压级，对照 NR 曲线（ISO 1996 解析式，31.5~8 kHz）或 NC 曲线（Beranek 表，63~8 kHz）评级。评级取「任一频带触碰的最高曲线」，不是各频带平均值。

1/1 ↔ 1/3 双向转换

1/1 → 1/3 时假定带内频谱平坦，每个 1/3 频带减 10·lg 3 = 4.77 dB；1/3 → 1/1 为三个频带能量求和。两个方向总能量守恒。

分段等效连续声级

Leq = 10·lg[ Σ tᵢ·10^(Lᵢ/10) / Σ tᵢ ]。每行一条「声压级 时长」，时长可省略（按等权处理）。适用于把不同工况的测量段合成为全天的等效声级。
