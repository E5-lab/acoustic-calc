计算方法

  • A 声级：LA = 10·log₁₀ Σ 10(Lᵢ + Aᵢ)/10，Aᵢ 由 IEC 61672 解析式计算，支持任意 1/3 倍频带中心频率。
  • NC：ANSI/ASA S12.2-2019 切线插值法，逐带插值曲线指数取最大值（31.5–8000 Hz 共 9 带），控制带标出起决定作用的频带。
  • NC 低频一致性：以 NC(SIL) 曲线为基准比较 31.5/63/125/250 Hz，超出 6–9 dB 提示可能引起严重不满，>9 dB 提示很可能引起（S12.2 频谱不平衡法）。
  • NR：ISO/R 1996 切线插值法，同理取各带最大 NR 指数。
  • RC Mark II：RC = round(均值(L₅₀₀, L₁₀₀₀, L₂₀₀₀))，参考曲线为以 1 kHz 为锚点、−5 dB/倍频程的直线，16/31.5 Hz 取 max(RC+25, 55)；≤500 Hz 超 5 dB 判 R，1000–4000 Hz 超 3 dB 判 H，否则 N。
  • QAI（品质评价指数）：SD低/SD中/SD高 分别为 16–63、125–500、1000–4000 Hz 三组偏差的能量平均，QAI = max(SD) − min(SD)，数值越小频谱越均衡（≤5 dB 通常视为均衡，为经验参考）。
  • RV（振动/颤振风险）：16/31.5 Hz ≥ 65 dB 或 63 Hz ≥ 70 dB 判中等风险，≥ 75/75/80 dB 判明确风险（ANSI/ASA S12.2-2019）。
  • 1/3 倍频程：1/3 倍频程输入先按各带能量合成倍频程（每带取上下限 f/√2 ~ f·√2 内的 1/3 带求和），再按上述倍频程方法评价。
  • 多测点能量平均：逐带 L̄ = 10·log₁₀( Σ10Lᵢ/10 / n )，即功率平均（非算术平均）。
  • 目标值对照：房间目标范围引自 ASHRAE Handbook HVAC Applications 常用 NC 推荐值，RC 取等价目标，判定以 NC 为主、RC 交叉参考。

数据来源：NC / RC — ANSI/ASA S12.2-2019；NR — ISO/R 1996；A 计权 — IEC 61672；房间目标 — ASHRAE 常用推荐值。本工具仅供工程估算，正式验收请以标准与仪器为准。
