01命令面板与 Toast

按 ⌘K / Ctrl K 唤起命令面板：对 58 个模块做模糊检索，支持 ↑↓ 选择、↵ 打开、最近使用记忆与操作指令。Toast 采用队列式堆叠，悬停暂停倒计时，适合替代零散的 alert。

全局可用

命令面板索引来自首页模块卡片，新增模块后自动收录；最近使用写入 localStorage，仅保存在本机。

04标签页与手风琴

标签页的下划线指示器随选中项滑动，支持 ← → 与 Home / End；手风琴用 grid-template-rows: 0fr → 1fr 做高度过渡，不需要测量内容高度。

逐倍频带声压级：63 Hz 至 8 kHz 共 8 带，低频段以 125–250 Hz 为主，呈现典型的交通噪声频谱特征。

30 分钟等效声级随时间变化：早晚高峰抬升约 6–8 dB，午间回落，夜间降至 45 dB 以下。

统计量：Leq 58.4 dB，L10 62.1 dB，L50 56.8 dB，L90 49.3 dB，Lmax 71.6 dB。

测量前校准声级计，记录温度、湿度与气压；测点距墙面不小于 1 m、距地面 1.2–1.5 m；每个测点至少采集 3 个时段，每段不短于 1 min，并注明主要声源与工况。
低频波长长、绕射能力强，普通多孔吸声材料在 125 Hz 以下效率很低；应优先考虑薄板/薄膜共振结构、亥姆霍兹共振器或加厚空腔，并同步检查侧向传声与结构振动。
本站结果为工程估算，用于方案比选与趋势判断；正式验收应以现行标准规定的测量方法、实验室报告或现场检测结论为准。

05模态框与抽屉

两者共用遮罩、滚动锁定与焦点管理：打开时焦点移入浮层，Tab 在内部循环，Esc 或点击遮罩关闭，关闭后焦点回到触发按钮。

06拖拽前后对比

用 clip-path 裁切上层画布，实现「处理前 / 处理后」频谱的直接对比。支持指针拖拽与键盘 ← →（Shift 加速），并同步 aria-valuenow。

示例为同一房间在加装吸声结构前后的 1/1 倍频程频谱：中高频峰值被削平，低频因共振结构略有改善。

07频谱曲线编辑器

Canvas 绘制的对数频率轴频谱，节点可直接拖动改变声压级。带悬停命中检测、参考曲线、A 计权总级实时计算，以及完整的键盘操作（← → 切换频带，↑ ↓ 调整，Enter 复位）。

08可排序数据表

点击表头在升序 / 降序间切换，aria-sort 同步更新；搜索框即时过滤，结果计数与空状态一并处理。表头在滚动容器内吸顶。

09动效与微交互

模块卡片跟随指针做轻微 3D 倾斜与聚光高光；结果数字变化时从旧值滚动到新值；骨架屏用位移高光提示加载。所有动效在系统开启「减少动态效果」时自动关闭。

3D 聚光卡片

指针在卡片内移动时，高光与倾斜角度实时跟随，最大倾斜 4–5°，离开后平滑复位。
