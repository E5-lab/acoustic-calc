# 声学计算工具箱 · Acoustic Toolbox

纯静态、零依赖的建筑与材料声学计算工具集，按**模块化视图**组织：顶栏采用**二级菜单**（总览 + 基础计算 / 材料与构件 / 房间声学 / 环境与振动 / 心理与声品质 / 模拟与可听化 六个分组），收纳声压级叠加、背景噪声评价、单位与换算、穿孔率、吸声阻抗、混响时间、墙体隔声、声屏障、弹簧减振、消声器、环境噪声评价、心理声学/声品质、振动评价、厅堂与扩声音质、室内音质模拟彩图、声场粒子动画、声学可听化共 17 个计算模块；哈希路由切换、深链可用。源码托管于 GitHub，可一键发布到 **Cloudflare Worker（Workers Builds）**。

## 模块

### ⓪ 弹簧减振器隔振效率计算书（`#/vibration`）

两种方法并行校核，三个子面板：**静变形法 · 计算书**、**频率比法 · 验算**、**反算与对照**。

- **方法一 · 静变形法（选型计算书）**：运行重量 W = (G₁+G₂)·K → 每只承载 P = W/N → 静态压缩量 δ = P/k → 动刚度 K_D = d·k → 固有频率 f₀ = 4.9823·√(K_D/P) ≈ 15.76/√δ → 频率比 z = f/f₀ → 传递率 T → 隔振效率 η = (1−T)×100%，输出 12 步计算书（公式+代入+结果），可复制/导出 CSV。
- **方法二 · 频率比法（含阻尼传递率）**：T = √{[1+(2Dz)²]/[(1−z²)²+(2Dz)²]}（D = 0 退化为无阻尼简化式 |1/(1−z²)|），与简化式并列对比，标注阻尼在共振区抑制放大、高频段略降效率的双重效应。
- **目标效率反算**：目标 η → 所需频率比 / 固有频率 / 静态压缩量 / 单只最大允许刚度（含阻尼时用二分法数值解）；附效率–频率比–静变形对照表。
- **判定与校核**：频率比宜 2.5 ~ 4、禁止 < 1.4（导则 7.4.2.4）；效率等级（优 ≥95% / 良 ≥90% / 合格 ≥80%）；荷载利用率、静压缩量过大/过小、共振放大等告警；传递率曲线（含阻尼与无阻尼双曲线 + 当前工作点）。
- 刚度单位支持 kg/mm / kg/cm / N/mm / kN/mm；动、静刚度比 d：钢弹簧 1.0、橡胶 1.5 ~ 2.3。

### ① 声压级叠加计算（`#/levels`）

分三个子面板：**多声源叠加**、**叠加方法与相干**、**修正与换算**。

- **多声源叠加**：任意数量声源（可带台数）能量叠加，给出总声级、能量平均级、各声源能量占比（含占比条）与「撤除后总级下降量」（治理优先级）；支持等声级声源（n 台相同声级，10·lg n）。
- **达标反算**：给定目标声级，逐个声源反算需降低多少 dB 才能使总级达标，并判断「仅降某一声源」能否可行。
- **增量法**：两声级差 → 增加值速算，附 0–20 dB 参考曲线图与速查表；等声级声源增量表。
- **相干叠加**：同频、给定相位差 φ 的矢量叠加（同相等强 +6 dB、正交退化为能量叠加、反相可完全抵消），附相位滑块与预设。
- **背景噪声修正**：从实测总级中扣除背景（含标准取整修正表与「差值 < 3 dB 不宜修正」判定）。
- **倍频带谱叠加**：两条 63–8000 Hz 频谱逐带能量叠加，附线性与 A 计权总级。
- **换算**：声压级 ↔ 声压；距离衰减（点声源 6 dB/倍距、线声源 3 dB/倍距）；声功率级 ↔ 声压级（点声源，Q = 1/2/4/8）。

### ② 背景噪声评价（`#/noise`）

- **A 声级（A-weighted）**：IEC 61672 解析式 A 计权（支持任意 1/3 倍频带中心频率），能量叠加法计算 dBA，同时给出线性（未计权）声级与 SIL 语言干扰级（SIL 按定义取倍频带 500/1000/2000/4000 Hz 均值）。
- **NC（Noise Criterion）**：ANSI/ASA S12.2-2019 切线插值法（31.5–8000 Hz 共 9 带），输出连续 NC 值、标准标号与控制频带。
- **NC 低频一致性检查**：以 NC(SIL) 曲线为基准比较 31.5/63/125/250 Hz（S12.2 频谱不平衡法），超出 6–9 dB 提示可能引起严重不满、>9 dB 提示很可能引起。
- **NR（Noise Rating）**：ISO/R 1996 切线插值法，输出连续 NR 值、标准标号与控制频带。
- **RC Mark II（Room Criterion）**：ANSI/ASA S12.2-2019 Annex D，输出 RC 数值 + 频谱质量判定（N 中性 / R 隆隆 / H 嘶声 / RH），并列出各频带相对参考曲线的超出量。
- **QAI（品质评价指数）**：SD 低/中/高（16–63 / 125–500 / 1000–4000 Hz 三组偏差的能量平均），QAI = max − min，量化频谱失衡程度。
- **RV（振动/颤振风险）**：16/31.5/63 Hz 按 S12.2-2019 阈值判定中等（65/65/70 dB）与明确（75/75/80 dB）风险。
- **1/1 与 1/3 倍频程**：1/1 模式含 16 Hz 带（10 带）；1/3 模式 16 Hz–10 kHz 共 29 带，按各带能量合成倍频程后评价（S12.2 各评价量本身为倍频程量），图表用对数频率轴。
- **房间目标值对照**：内置 13 类常用房间的 NC 目标范围（引自 ASHRAE Handbook HVAC Applications 常用推荐值），自动判定达标并给出超出量。
- **多测点能量平均**：粘贴多条频谱逐带按功率平均（10·log₁₀(Σ10^(L/10)/n)），一键填入计算。
- **结果导出**：一键复制文本摘要、导出 CSV（含各频带实测 / RC 参考 / 超出量）。
- **频谱对比图**：Canvas 对数频率轴绘制实测频谱与 NC / NR / RC 参考曲线叠加。

### ③ 穿孔率计算（`#/perforation`）

参考 E5-lab/AC_Calc 的实现并扩展，全部公式按「单元面积」统一推导：

- **四种阵列形制**：正方形对称阵列 σ = πd²/(4P²)、45° 菱形错排 σ = πd²/(2P²)、矩形非等边错排 σ = πd²/(2·P1·P2)、等边三角形错排（六方，几何精确解）σ = πd²/(2√3·P²)。
- **派生量**：单孔面积、单元面积、孔数密度（个/m²）、孔径/中心距比、剩余板面比例。
- **阵列示意图**：Canvas 按当前参数等比绘制孔阵，标注孔径、孔心距、行距与单元面积虚线框。
- **反算中心距**：给定目标穿孔率反求 P（矩形错排固定 P2 求 P1），含回代自检。
- **加工校核**：孔间剩余壁厚 < 0.8 mm 提示加工风险；σ > 30% 提示结构校核；σ < 0.3% 提示进入微穿孔板区间。
- **微穿孔板共振估算**：f₀ = c/(2π)·√(σ/(t′·D))，t′ = t + 0.85d（Maa 端部修正），附适用范围判定与 1/4 波长参考。
- **板材开孔估算**：按板面尺寸折算总孔数与总开孔面积。
- **导出**：复制文本摘要、导出 CSV。

### ④ 多孔吸声材料阻抗（`#/absorber`）

- **Delany–Bazley 模型**：由流阻率 σ 与频率推算特征阻抗 Zc/(ρ₀c₀) 与复波数 k/k₀（Bies & Hansen 系数）。
- **层状传递**：刚性背衬 Zs = Zc·coth(γd)；带空腔时按空气层阻抗做层状介质传递。
- **倍频带法向吸声系数**：63–4000 Hz 共 7 带，附 NRC（250/500/1k/2k 均值，0.05 取整）与适用性判定（0.01 ≤ X ≤ 1）。
- **流阻率预设**：9 类常用多孔材料（玻璃棉/岩棉/聚酯纤维/三聚氰胺泡沫等）。
- **厚度建议**：按目标频率 1/4 波长条件反算层厚。

### ⑤ 室内混响时间 RT60（`#/rt60`）

- **Sabine / Eyring**：125–4000 Hz 六带逐带计算，两式对照。
- **材料吸声系数库**：内置 20 类常用表面构造的倍频带吸声系数，支持自定义系数。
- **表面归集**：列出部分表面，其余自动按所选材料计入；空气吸收按 ISO 9613-1 典型值计入（可关闭）。
- **用途判定**：13 类房间用途的中频推荐混响范围，达标判定 + 区间条可视化。
- **改进建议**：反算达标所需增加的吸声量与等效吸声面积。

### ⑥ 墙体隔声量 Rw / STC（`#/stc`）

- **质量定律**：R = 20lg(mf) − 48，由材料密度×厚度自动算面密度（12 类材料预设）。
- **计权隔声量 Rw（GB/T 50121-2005，等效 ISO 717-1）**：表 3.1.2 基准曲线在 100–3150 Hz 共 16 个 1/3 倍频带（或 125–2000 Hz 共 5 个倍频带，限值 10 dB）逐 dB 平移，取「不利偏差之和 ≤ 32 dB」的最大值；不设 8 dB 单带限值（与 ASTM 不同）。
- **频谱修正量 C / Ctr**：按表 3.1.3 的 A 计权频谱（粉红噪声 / 交通噪声）计算，给出 Rw(C; Ctr) 标准表述与 Rw+C、Rw+Ctr。
- **国标限值对照**：内置 GB 50118-2010《民用建筑隔声设计规范》与 GB 55038-2025《住宅项目规范》共 14 条构件类限值（分户墙、外墙、户门、外窗、教室隔墙等），自动判定达标并给出余量与达限所需 Rw。
- **STC 评级**：ASTM E413，125–4000 Hz 共 16 个 1/3 倍频带标准轮廓逐 dB 拟合（缺量之和 ≤ 32，单带 ≤ 8），与国标 Rw 同屏对照。
- **三种输入**：单层板 / 双层构件经验估算 / 直接填入 100–4000 Hz 共 17 带 1/3 倍频带实测值（同时覆盖两标准频段）。
- **吻合频率提示**：f_c = c₀²/(1.8·c_L·t)，落在评价范围内时提示实测值会低于估算。
- **逐带明细**：隔声量、两标准轮廓线与偏差（超限标红），图表可切换 GB 基准 / ASTM 轮廓 / 同显。

### ⑦ 声屏障衰减（`#/barrier`）

- **菲涅尔数法**：由声源/屏障/接收点几何计算程差 δ 与 N = 2fδ/c₀。
- **双公式**：Maekawa 与 Kurze–Anderson，可切换；默认 24 dB 实用上限（可调）。
- **声源谱库**：9 类典型声源（道路交通/轨道/施工/风机/水泵/变压器等），A 计权能量叠加得插入损失。
- **断面示意图**：Canvas 按尺寸绘制声源、屏障、接收点、视线与绕射路径，标注程差与菲涅尔数。
- **视线校核与高度反算**：屏障顶低于视线时直接提示无效；给定目标插入损失反算所需屏障高度。

### ⑧ 消声器计算（`#/muffler`）

分三个子面板：**阻性**、**抗性（扩张室 + 共振腔）**、**组合验算**。

- **阻性消声**：按 GB/T 50087-2013 式 6.3.1 计算高频上限失效频率与静态插入损失，配别洛夫（Belov）对照经验式；含高频失效折减、流速引起的再生噪声与压力损失校核；片式 / 管式通道几何联动。
- **抗性消声**：扩张室一维平面波解（传递损失 TL 随频率起伏，含上限截止频率）；共振腔 Helmholtz 共振频率与 TL 峰值；可叠加多节扩张室 / 多共振腔串联。
- **组合验算**：阻性 + 抗性串联，给出 A 计权插入损失与装前 / 装后频谱图；材料与声源预设可一键载入。
- **图表**：Canvas 绘制各频段插入损失 / TL 曲线与频谱叠加。

### ⑨ 单位与换算（`#/db`）

分四个子面板：**声级相加/背景修正**、**单位换算**、**距离衰减**、**计权网络速查**。

- **声级相加**：任意多个声压级能量叠加求和与增加值；总量扣背景（背景修正）并提示差值 < 3 dB 不可用。
- **单位换算**：声压级 / 声压 / 声强 / 声强级 / 声功率 / 声功率级 六量任选其一、其余自动联动（平面波下 I = p²/(ρc)）。
- **距离衰减**：点 / 线 / 面声源衰减（面源含近场/远场临界 a/π），以及由声功率级 L_W 反算点声源声压级（含指向性 Q）。
- **计权网络**：A / C / Z 计权衰减值速查表（相对 1000 Hz）。

### ⑩ 环境噪声评价（`#/env`）

分六个子面板：**Leq 与统计声级**、**Ldn/Lden**、**NPL/TNI**、**噪声评价数 NR**、**户外声传播(ISO 9613-2)**、**公路交通噪声**。

- **等效/统计声级**：Leq（能量平均）与 L5/L10/L50/L90/L95 百分位（L_N 表示被超过 N% 的时间）。
- **昼夜声级**：Ldn（夜 +10 dB）、Lden（傍晚 +5 / 夜 +10）按 15/9h、12/3/9h 标准时段。
- **NPL/TNI**：噪声污染级 NPL = Leq + (L10−L90)（或 Leq + 2.56σ）；交通噪声指数 TNI = 4(L10−L90) + L90 − 30。
- **NR 曲线**：由 1/1 倍频带谱求噪声评价数 NR（取各带隐含值最大值）。
- **户外传播**：ISO 9613-2 A 计权声传播——几何发散 + ISO 9613-1 大气吸收（精确解析公式）+ 地面效应（简化），逐带输出。
- **交通噪声**：无限长线声源模型，由车流量/车速/距离预测 L_pA。

### ⑪ 心理声学 / 声品质（`#/psycho`）

分五个子面板：**响度换算**、**总响度/尖锐度**、**粗糙度/抖动度**、**感觉噪声级 PNL**、**STIPA/STI**。

- **响度换算**：响度级(phon) ↔ 响度(sone) 精确换算（N = 2^((L_N−40)/10)）。
- **总响度/尖锐度**：由 1/1 倍频带声压级估算总响度（sones，工程近似）与尖锐度（acum，DIN 45692 近似）。
- **粗糙度/抖动度**：给定调制频率、调制深度与整体响度，按 Zwicker 经典模型估算 R（asper，峰值≈70Hz）与 F（vacil，峰值≈4Hz）。
- **感觉噪声级**：由 1/1 倍频带声压级估算 PNL（dB），低/高频比中频更"吵"。
- **STIPA/STI**：由 14 个调制带 MTF（0~1）计算语言传输指数 STI 并评级（很差/差/一般/良好/优秀）。

### ⑫ 振动评价（`#/vibeval`）

> 区别于 ⓪ 弹簧减振（隔振设计），本模块聚焦"振动评价"。

分五个子面板：**振动级换算与 a/v/d 互算**、**计权振动级与 aw**、**人体暴露评价(ISO 2631-1)**、**VDV**、**GB 10070 环境振动标准**。

- **振动级换算**：加速度/速度/位移级（参考值 10⁻⁶/10⁻⁹/10⁻¹²）及三者按频率互算。
- **计权振动级/aw**：按 ISO 2631-1 频率计权（Wb/Wc/Wd/We，1/1 倍频带近似）求计权总振动级与计权 RMS 加速度 aw。
- **暴露评价**：由 aw 与每日暴露时长按 √(t) 缩放，对照 8h 行动值 0.5、暴露限值 1.15 m/s² 判定。
- **VDV**：振动剂量值（稳态近似 VDV = a_rms·Cf·T^¼），对照 8h 行动值 8.5、暴露限值 17。
- **GB 10070**：城市区域环境振动标准（铅垂向 Z 计权，dB）六类地带昼/夜限值判定。

### ⑬ 厅堂与扩声音质（`#/roomq`）

> 区别于 ⑤ 混响时间 RT60（吸声材料库），本模块聚焦"音质评价量"与"扩声系统预测"。

分五个子面板：**RT60/EDT**、**C50/C80 与 D50**、**中心时间 Ts**、**强度因子 G**、**扩声系统声场预测**。

- **RT60/EDT**：由 T₁₀/T₂₀/T₃₀ 衰减时间外推 RT60 与 EDT。
- **清晰度/定义度**：由脉冲响应能量份额（E₅₀/E₈₀/E_tot）求 C50、C80 与 D50。
- **中心时间 Ts**：由逐点时间/能量求 Σt·E(t)/ΣE(t)。
- **强度因子 G**：G = Lp − Lw + 10lg(4πr²)。
- **扩声预测**：由房间常数 R、临界距离 r_c、直达+混响声场，预测听众处声压级 Lp。

### ⑭ 室内音质模拟彩图（`#/sim`）

> 几何声学（镜像声源 + 三维光线追踪）仿真，版式对齐 Odeon / CATT 的分布图：**左侧三维轴测模型 + 右侧指标色标标杆**，输出**逐倍频带声场彩图 + 混响时间分布 + 接收点 ISO 3382 估算**，可导出 **PNG**。
> 方法源自公开文献（Allen & Berkley 镜像声源法、Kuttruff 光线追踪、Schroeder 反向积分），与 Odeon / CATT / Raynoise 同类方法体系，为**自研实现**；定位为方案估算与可视化，非验收级。

- **房间模型**：矩形（长×宽×层高）+ 可选竖向内隔墙；吸声系数 α 可由材料库中频取值；散射系数 s（ISO 17497-1）可调。
- **逐倍频带**：125 Hz ~ 4 kHz 六个倍频带 + 中频均值（500 Hz + 1 kHz）；各带独立统计 Sabine / Eyring+空气吸收 / 模拟 T30 / EDT / C50 / C80 / D50 / Ts，并输出全带对照表。
- **彩图指标 7 种**：混响时间 T30、早期衰减时间 EDT、相对声压级 L、清晰度 C50、明晰度 C80、定义度 D50、中心时间 Ts（Ts 为反向色标）。
- **三维轴测模型（左栏）**：地面铺该指标在该频带的模拟分布彩图，天花与竖向格栅构成线框笼架，内隔墙单独着色；「视角方位」可 0–360° 旋转。
- **指标色标标杆（右栏）**：竖向色带（蓝→青→绿→黄→红，顶为高值）+ 按 1/2/2.5/5/10 整齐步长标注的数值刻度（首末以 ≥ / ≤ 表示分位截断）+ 蓝色三角标出**接收点**读数；可一键导出 PNG 用作汇报插图。
- **物理一致性**：模拟 T30 落在 Eyring+空气吸收 与 Sabine 之间（回归测试覆盖 α = 0.05 ~ 0.40，比值 1.02 ~ 1.18）。

### ⑮ 声场粒子动画（`#/simfx`）

> 声学可视化：把光线追踪得到的声线当作**声粒子**，从声源出发、在房间内往复反射并逐次被界面吸收（亮度与半径随剩余能量衰减）。可导出 **GIF** 或 **MP4 / WebM**。

- **2D / 3D 可选**：2D 为俯视平面投影（看平面反射路径），3D 为斜轴测（看地面/墙面/天花板的往复反射），可 0–360° 旋转。
- **动画参数**：粒子数、传播速度（m/s，真实声速 343 m/s，放慢才看得清）、拖尾长度、完整光路显示/隐藏。
- **导出**：GIF 为逐帧离屏渲染后编码（自研 **GIF89a 编码器**，零依赖：256 色全局调色板 + 4×4 Bayer 抖动 + 变字长 LZW + NETSCAPE2.0 循环）；视频走浏览器 `MediaRecorder`（Chrome/Edge 一般出 MP4，Firefox 出 WebM）。
- 标注的物理时间（ms）与声程（m）为真实值，与播放速度无关；用于教学演示与方案沟通，不作为量化依据。

### ⑯ 声学可听化（`#/aural`）

> 把计算结果变成**能听见的声音**（浏览器本地 Web Audio 合成，上传音频不出本机）。

- **A. 混响可听化 A/B**：同一干信号分别与方案 A / B 的脉冲响应做 FFT 快速卷积，直接试听不同混响时间下的音质差异。
  - 脉冲响应两种来源：① 直接指定各倍频带 RT（含低频倍率偏移，模拟低频混响偏长）；② 按房间几何光线追踪，由接收点能量时程逐带合成（保留早期反射离散结构）。
  - 干信号可选合成语音音节 / 拍手脉冲 / 粉噪猝发，或上传自己的音频（取前 8 s 单声道）。
  - 支持 A → B 轮流对比播放、Schroeder 衰减曲线对照、A / B 各自下载 WAV。
- **B. 隔声试听**：按倍频带频谱整形噪声作声源，逐带减去隔声量 R 得到透射声，试听**阻隔前 / 后**的响度差；给出线性降噪量与 A 计权降噪量（IEC 61672）、计权隔声量 R_w 估算（GB/T 50121 参考曲线偏移法），并画出阻隔前后倍频带谱对比。
  - 内置多种构件隔声量预设（可直接改任一带的 R）与多种典型噪声源。

### ⑰ 小房间与室内声场（`#/smallroom`）

> 矩形房间简正频率分布、Bonello 低频均匀性准则、Schroeder 频率、房间常数与临界距离、稳态声压级（直达+混响）及多声源叠加、空气吸收（ISO 9613-1）。

- **简正频率**：f = (c/2)√[(n_x/L)² + (n_y/W)² + (n_z/H)²]，按轴向/切向/斜向分类并统计简并。
- **Bonello 准则**：按 1/3 倍频程统计模态计数，要求单调不减且空带不连续，否则低频易染色。
- **Schroeder 频率** f_s = 2000√(RT60/V)；房间常数 R = Sᾱ/(1−ᾱ)、临界距离 r_c = 0.141√(Q·R)。
- **稳态声压级** Lp = Lw + 10lg[Q/(4πr²) + 4/R]，多声源按能量叠加。
- **空气吸收**（ISO 9613-1）：逐倍频带 α（随温度 / 湿度 / 气压变化）。

### ⑱ 吸声结构设计（`#/absdesign`）

> 用传递矩阵法（TMM）计算吸声结构逐频带吸声谱，覆盖微穿孔板（马大猷）、多孔材料（Delany–Bazley / Miki）、薄板/薄膜共振与吸声降噪量 ΔL。

- **微穿孔板**：给定孔径 d、板厚 t、穿孔率 p、空腔 D，求法向吸声系数谱与共振频率 f₀。
- **多孔材料 + 空腔**：由流阻率经 Delany–Bazley / Miki 模型得特性阻抗与传播常数，串联空气腔求吸声谱（NRC）。
- **薄板 / 薄膜共振**：f₀ = (c/2π)√(ρ₀/(m·d))。
- **吸声降噪量** ΔL = 10lg(A₂/A₁)，可由背景噪声谱估算处理后 A 声级。

### ⑲ 隔声与撞击声进阶（`#/insdesign`）

> 在前端「墙体隔声量 Rw/STC」基础上提供进阶层级计算，覆盖专业声学书籍中常见工程估算。

- **单层密实构件**：质量定律 R(f) = 20lg(m·f)−48 隔声谱，并提示吻合频率 fc = c₀²/(1.8·c_L·t)（fc 附近隔声量陡降）。
- **双层构造**：质量-空气-质量共振频率 f₀ = (c₀/2π)√((m₁+m₂)/(m₁·m₂·d))、共振低谷、空气层高频增益与腔体吸声阻尼。
- **隔声罩 / 围护插入损失**：NR = TL + 10lg(S/A_inside)（单值或 1/3 倍频带谱）。
- **浮筑楼板 / 弹性垫层**：撞击声改进量 ΔL(f) = 20lg(f/f₀) 与共振频率 f₀ = (1/2π)√(s′/m)。
- **组合与侧向传声**：多路径能量叠加 R_total = −10lg(Σ10^(−Rᵢ/10))，低频常由最薄弱（侧向）路径主导。

### ⑳ 设备与管道声学（`#/hvacnoise`）

> 面向机房 / 风系统噪声控制的工程估算，与「消声器」「环境噪声」模块互补。

- **设备噪声 → 房间声压级**：Lp = Lw + 10lg[Q/(4πr²) + 4/R]，17 频带逐带计算并汇总 A 声级。
- **风管路径衰减**：直管（L×衰减率）、弯头（截止频率 fc = c₀/2w 之上每倍频程约 +3 dB，封顶 10 dB）、末端反射（开口端损失，封顶 25 dB）逐频带叠加 → 出口 Lw → 房间声压级。
- **风管元件传声损失**：直管 / 弯头 / 末端反射单件速算。
- **声功率测定 ISO 3744 / 3746**：Lw = L̄p + 10lg(S/S₀) − K₁ − K₂，反射面上半球面 S = 2πr²、矩形包络测量面，含背景噪声与环境修正。

### ㉑ 电声与语言清晰度（`#/pasystem`）

> 扩声系统方案比选：覆盖、增益、清晰度、功率一次算清。

- **覆盖与声压级**：临界距离 rc = 0.141·√(Q·R)、直达/混响声能与 D/R、指定距离声压级（按 1 kHz 频带）。
- **扩声可用增益**：G ≈ 20lg(rc/r_mic) − 10lg(NOM) − 稳定裕量，与所需电声增益对比判定啸叫风险。
- **STIPA 预测**：7 倍频带 × 2 调制频率（IEC 60268-16 配对），MTF = MTF_SNR × MTF_rev，STI = Σlog2(1+MTF)/14（与「心理声学」模块同口径），逐带信噪比与 MTF 表。
- **扬声器电功率**：由灵敏度（1 m/1 W）与所需声功率级反算，建议留 3 dB 功率余量。

### ㉒ 环境噪声进阶（`#/noisemap`）

> 在「环境噪声评价」基础上补齐户外面源预测与达标判定。

- **噪声等值线图**：最多 3 个点声源，ISO 9613-2 传播（球面发散 + 大气吸收 + 地面效应）逐网格能量叠加，marching squares 提取 5 dB 等值线，Canvas 热力图 + PNG 导出。
- **道路交通噪声**：线声源模型 Lp = LwL − 10lg(2πr) − A_atm − A_gr（车流量 / 车速 / 车型比 / 地面）。
- **限值达标判定**：GB 3096-2008 声环境功能区（0/1/2/3/4a/4b 类，昼/夜）、GB 55016-2021 表 2.1.3（外部噪声源传入室内）与表 2.1.4（内部设备传播至室内），含 2/3/4 类区放宽 5 dB 规则。

### ㉓ 扬声器箱体设计（`#/speakerbox`）

> 电声器件级设计：从 T/S 参数到箱体与导风管，一次算清低频系统。

- **T/S 参数与 Vas**：Vas = ρc²·Sd²/(Mms·ωs²)；附加质量法 Mms = ΔM/[(Fs/Fm)²−1]；阻抗峰法 Qms = Fs·√R₀/(F2−F1)、Qes = Qms/(R₀−1)、Qts = Qms·Qes/(Qms+Qes)；参考效率 η₀ = 4π²/c³·Fs³·Vas/Qes 与灵敏度（半空间 112.1 + 10lg η₀，1% 效率 ≈ 92 dB/W/m）。
- **封闭箱（二阶）**：α = Vas/Vb、fc = Fs·√(1+α)、Qtc = Qts·√(1+α)；解 v² + v(2 − 1/Qtc²) − 1 = 0 得 f3；Qtc > 0.7071 时隆起 2Qtc²/√(4Qtc²−1)，峰频 fc·√(2Qtc²/(2Qtc²−1))；可由目标 Qtc 反算容积。
- **倒相箱（四阶，Small / DAFx-14 系统函数）**：G(s) = s⁴/[s⁴ + a₃s³ + a₂s² + a₁s + 1]，h = Fb/Fs、α = Vas/Vb、f₀ = √(Fs·Fb)，含箱损 Ql。给出 f3、通带纹波、对齐类型判定（A₁ = A₂ = A₃ = 0 即 B4）、幅频与**群延迟解析曲线**；支持按给定 Vb 数值搜索最平坦调谐 Fb。
  - 自校验锚点：Qts = 0.3827、Vb = Vas/√2、Fb = Fs 时精确退化为四阶巴特沃斯（纹波 0 dB、f3 = Fs）。有限 Ql（默认 7）会使 f₀ 附近下陷、f3 上移——这正是理论计算与实测不符的常见原因。
- **导风管**：Leff = c²S/((2πFb)²·Vb)，L = Leff − k·D，端修正 k = 0.732（一端障板 + 一端自由）/ 0.85（两端法兰）/ 0.61（两端自由）；支持由管长正算调谐频率；端口峰值风速由半空间单极子 p = ρωU/(2πr) 反算，按 12 / 18 / 25 m/s 三档给出风噪评价。
- **箱体尺寸**：按内部净容积与三边比例（黄金 / Keele / 经典 / 立方体）求内部尺寸；净容积扣除单元、倒相管、加强筋占用并计入吸声棉等效增益。

### ㉔ 分频器设计（`#/crossover`）

> 电声分频网络：元件值、响应、补偿一次算清。

- **前提**：功放输出阻抗 ≈ 0，按「电压驱动 + 负载 Z」推导，不能直接套用双端接 g 值原型表（那样在电压源下得不到巴特沃斯）。
- **元件值**：一阶 L = Z/ω₀、C = 1/(ω₀Z)；二阶 C = Q/(ω₀Z)、L = Z/(Qω₀)（五种 Q 预设：巴特沃斯 0.707 / LR2 0.5 / 贝塞尔 0.577 / 契比雪夫 0.864、0.957）；三阶巴特沃斯 L₁ = 1.5Z/ω₀、C₁ = 4/(3ω₀Z)、L₂ = 0.5Z/ω₀（与行业表格 0.955 mH / 13.26 µF / 0.318 mH @8 Ω·2 kHz 逐项吻合）；四阶 LR4 = 两级相同二阶巴特沃斯级联，四阶巴特沃斯由约束方程数值求解。
- **响应与极性**：给出低通 / 高通 / 合成的逐频曲线。二阶高低通在分频点相差 180°，**必须反接一路**（否则完全抵消），反接后二阶巴特沃斯约 +3 dB 隆起；**LR2 / LR4 按正确极性合成平直**。
- **阻抗补偿**：Zobel 网络 Rz = k·Re（默认 1.25）、Cz = Le/Rz²，把中高频阻抗拉回 Re。
- **L-pad**：保持输入阻抗不变的前提下衰减 X dB，R_series = Z(1−k)、R_shunt = kZ/(1−k)，并回算校验输入阻抗。
- **辅助**：单元灵敏度差匹配建议、由现成 L / C 反算实际分频点。

### ㉕ 线阵列覆盖设计（`#/linearray`）

> 从吊挂几何反推覆盖角与箱体规模，再核算指向性、旁瓣、栅瓣与近远场衰减。

- **覆盖几何**：Σ = atan(h<sub>c</sub>/D<sub>近</sub>) − atan(h<sub>c</sub>/D<sub>远</sub>)（h<sub>c</sub> 为阵列中心离耳高），每节张角 = Σ/(N−1)，整体垂直覆盖 = Σ + 单箱覆盖角；可按单节张角上限反算所需箱体数，并给出近远场声压差（近场 10lg 比、远场 20lg 比）。
- **逐箱张角**：把总覆盖角切成 N 个扇区，每箱瞄准本扇区中心；q = 1 等角，q > 1 时底部张角变大、顶部变小（J 形阵列，能量偏向远场）。输出逐箱瞄准俯角、节间张角、中心高与落点距离。
- **垂直指向性**：离散阵列因子 |AF| = |Σaₙe^{jnψ}|/Σaₙ，ψ = k·d·sinθ + ψ₀，支持电子偏转与幅度锥化（升余弦 / 线性）。给出 −6 dB 覆盖角（专业音箱标称覆盖角定义）、第一零点（sinθ = λ/(Nd)）、第一旁瓣（有限阵约 −12.8 dB，N→∞ 收敛到 −13.26 dB）、全空间无栅瓣频率上限 c/(2d)（即 d < λ/2）与相邻单元电子延时。
- **近场—远场**：路程差 λ/4 → r₁ = L²/(2λ)（柱面波 −3 dB/倍程区边界），λ/8 → r₂ = L²/λ（此后转为球面波 −6 dB/倍程）；给出目标距离的柱面/球面两种预测值与多箱叠加增益（低频相干 +20lgN、高频非相干 +10lgN）。
- **梳状滤波**：相邻声源路程差 Δ = d·sin|θ|，陷波 f<sub>m</sub> = (2m+1)·c/(2Δ)；可反解给定上限频率下的最大允许间距。

### ㉖ 波动与乐音计算（`#/wave`）

> 声学最底层的那批量：声速、波长、声强、声阻抗、分贝比值，以及乐音与共振。

- **声速**：空气按干空气／水蒸气混合物求 γ 与摩尔质量（20 ℃ 干空气 343.3 m/s、饱和湿空气约 344.6 m/s、0 ℃ 331.4 m/s，密度 1.204 kg/m³），并与简化式 331.4 + 0.6T、开方式 331.3·√(T_K/273.15) 三式对照；纯水采用 UNESCO / Marczak 五次多项式（0 ℃ 1402.4、20 ℃ 1482.3 m/s）。
- **波长 ↔ 频率**：λ = c/f，同时给出周期、波数、λ/2（房间轴向模态）与 λ/4（1/4 波长吸声结构起效尺度），附常用倍频带波长速查表；也可由波长反算频率并给出最接近音名。
- **自由场声强**：I = Q·P/(4πr²)、L_I = 10lg(I/I₀)、L_p = L_W + 10lg(Q/4πr²)，距离表与衰减曲线验证每倍距离 −6 dB；Q = 1 / 2 / 4 对应全空间 / 半空间 / 四分之一空间。
- **特性声阻抗与界面**：Z = ρc（内置 18 种介质库），垂直入射 R_p = (Z₂−Z₁)/(Z₂+Z₁)、τ = 4Z₁Z₂/(Z₁+Z₂)²；斜入射按法向声阻抗 Z/cosθ 并用 Snell 定律求折射角，超过临界角即全反射（空气→水 θ_c = 13.37°，这正是水面掠射几乎全反射的原因）。空气→水 TL ≈ 29.5 dB、空气→钢 ≈ 44.5 dB。
- **比值 ↔ 分贝**：功率量 10lg、场量 20lg，双向换算（功率比 2 = 3.01 dB、场量比 2 = 6.02 dB）。
- **乐音**：十二平均律（A4 = 440 Hz），频率 ↔ 音名 ↔ MIDI ↔ 音分偏差；两音音程（半音 / 音分）与拍频，并按 0.5 / 20 / 300 Hz 划分拍音区、粗糙区与分离区。
- **管与弦共振**：开管 fₙ = n·c/(2L_eff)（全部谐波）、闭管 fₙ = (2n−1)·c/(4L_eff)（仅奇次），管口修正每端 0.6r；弦 fₙ = n/(2L)·√(T/μ)，线密度可由直径与材料密度换算。
- **多普勒效应**：f′ = f·(c + v_o)/(c − v_s)，给出前后波长压缩 / 拉长、马赫数，Ma ≥ 1 判定为激波（音爆）。

### ㉗ 音频电平与阻抗（`#/audiolevel`）

> 电声工程里最容易记混的一组量：dBV / dBu / dBm / dBFS 到底以谁为 0 dB，2.83 V 与 1 W 差多少，多只并联是 +3 dB 还是 −3 dB，长线会把阻尼系数拖到多少。

- **电平换算**：dBV（1 V 基准）、dBu（√0.6 = 0.7746 V 基准，与 dBV 相差 2.2185 dB）、dBm（1 mW 功率量，须指定负载；600 Ω 下 0 dBm = 0 dBu）、dBW（1 W 基准）、dBFS（需先选定满刻度，内置 +15 ~ +24 dBu 五档，+24 dBu = 12.276 V）。任一单位输入即展开全部表示，并给出峰值、峰峰值与距削波余量；附七条常用电平锚点（−10 dBV / +4 dBu / 100 W·8 Ω 等）对照。
- **灵敏度互换**：SPL(2.83 V) = SPL(1 W) + 10·lg(8/Z)。8 Ω 时两套标注数值相同；4 Ω 用 2.83 V 标注会比 1 W 标注「好看」3 dB，16 Ω 反之 −3 dB；同时给出 1 V/1 m 与 1 W 对应电压。
- **串并联**：恒压功放模型下，并联每只拿到满电压 → 总功率 ×N（每加倍 +3 dB）；串联每只拿到 U/N → 总功率 ÷N（每加倍 −3 dB）；串并联（每串 s 只、共 p 串）总阻抗 s·Z/p、增益 10lg(p/s)，可在总阻抗与声压之间折中。
- **功放 → 声压级**：SPL(r) = SPL<sub>1W/1m</sub> + 10lg P − 20lg r，每倍距离 −6 dB；多只非相干 +10lg N、理想相干 +20lg N；全空间（4π）比半空间低 3 dB。附声压-距离曲线。
- **功放选型**：由目标声压级与距离反算每只连续功率，叠加波峰因数（正弦 3 dB / 粉噪 8 dB / 流行 10 dB / 古典 16 dB）得峰值功率，叠加余量得建议功放功率；工程惯例取音箱连续功率的 1.5~2 倍。
- **线材与阻尼**：R = ρL/A（回路按往返计，铜 2.5 mm² = 6.90 mΩ/m，AWG 12 = 5.21 mΩ/m，含铜/铝/银/CCA 与温度系数）；阻尼系数 DF = Z<sub>负载</sub>/(Z<sub>功放</sub> + R<sub>回路</sub>)，≥50 优秀、20~50 良好、10~20 可接受、<10 低频拖尾；线损 20lg(Z/(Z+R_s))。
- **允许线长**：由线损上限（常用 0.5 dB）与阻尼下限（常用 20）两条约束取严，反算允许回路电阻与单程线长，并给出 12 档公制 + 14 档 AWG 对照。8 Ω / 2.5 mm² / DF≥20 时约 27.6 m。
- **IEC 60268-5 校核**：扬声器阻抗模最小值不得低于标称的 80 %（8 Ω → 6.4 Ω）；按最小阻抗估峰值电流，并给出功放功率建议区间。

### ㉘ 频谱分析与计权（`#/spectrum`）

> 把测得的窄带数据整理成能下结论的形式：归并到倍频程、施加 A/C/Z 计权、对照 NR / NC 曲线评级。全部按能量运算，归并前后总能量守恒。

- **频带归并**：粘贴任意频率点（窄带 FFT、1/3 倍频程或零散读数），按能量求和归并到 1/1 或 1/3 倍频程。ISO 266 标称频率与带宽（1/1 相对带宽 70.71 %、1/3 为 23.16 %，1 kHz 的 1/3 带为 891.3~1122.5 Hz）；归并前后总能量应一致，若不一致说明有数据点落在标称频带表之外。
- **A / C / Z 计权**：按 IEC 61672-1 解析式计算（1 kHz 处 A 与 C 均为 0 dB；A 在 2 kHz 达 +1.2 dB 峰值，31.5 Hz 为 −39.5 dB；C 在 31.5 Hz 与 8 kHz 均约 −3 dB），给出总级 L_Z / L_A / L_C。
- **L_C − L_A**：判断「A 计权是否够用」的常用指标。差值 < 10 dB 为常规频谱；10~20 dB 说明低频含量偏高；> 20 dB 为明显低频主导，单看 dB(A) 会低估烦恼度，应同时给出倍频程谱。附带频谱重心（能量加权平均与几何平均频率）与 PSIL / SIL 语言干扰级。
- **NR 评级**：ISO 1996 解析式 L = a + b·N（N 即曲线在 1 kHz 处的声压级），覆盖 31.5 Hz ~ 8 kHz。评级取各频带所需 N 的最大值向上取整，并指出主导频带与各带余量；例如 NR-30 在 63 Hz 为 59.2 dB、8 kHz 为 22.9 dB。
- **NC 评级**：Beranek 表（63 Hz ~ 8 kHz，NC-15 至 NC-70，按 5 递增，非整 5 线性插值）。NC-30 = 57/48/41/35/31/29/28/27。同样取「任一频带触碰的最高曲线」而非平均——63 Hz 单点 70 dB 即可把频谱拉到 NC-50，即便其余频带只有 20 dB。
- **1/1 ↔ 1/3 双向转换**：1/1 → 1/3 假定带内平坦，每个 1/3 频带减 10·lg 3 = 4.77 dB；1/3 → 1/1 为三个频带能量求和。往返闭合，总能量守恒。
- **分段等效声级**：L_eq = 10·lg[ Σ tᵢ·10^(Lᵢ/10) / Σ tᵢ ]，可把不同工况的测量段合成为全天等效声级；并对比「忽略时长的能量求和」以显示时长权重的影响。

### ㉙ 扩散体设计（`#/diffuser`）

> 八类扩散体的参数化几何设计，基于公开经典声学公式（Schroeder 1975；Cox & D'Antonio）。

- **QRD 二次余数**：dₙ = (n² mod N)·λ₀/(2N)，共 N 个井，宽频均匀散射，控制室/录音棚后墙首选。N=7、f₀ = 1 kHz（λ₀ = 343 mm）时井深为 0 / 24.5 / 98 / 49 / 49 / 98 / 24.5 mm。
- **PRD 原根**：dₙ = (gⁿ mod N)·λ₀/(2N)，g 为 N 的原根，共 N−1 个井；散射图样与 QRD 不同，具方向控制能力。
- **MLS 最大长度**：本原多项式驱动的 LFSR，长度 2^m − 1（m = 2~10），仅两种井深（0 / λ₀/2），功率谱平坦、制造最简单。
- **2D QRD**：X/Y 两轴独立素数序列，d<sub>ij</sub> = (sX<sub>i</sub> + sY<sub>j</sub>)·(λ₀/2)/[(Nx−1)+(Ny−1)]，实现半球散射。
- **Skyline / Binary / Wave / Fractal**：开口井「天际线」阶梯剖面；反射井（λ₀/4）与吸声井交替的二元振幅光栅；d(x) = (λ₀/4)(1 − cos 2πx/Λ) 的光滑波纹曲面（最大井深 λ₀/2）；QRD 序列两尺度嵌套的自相似分形构造。

输出设计波长、井深序列、最大/最小井深、周期宽度、基于几何的有效频段（f<sub>low</sub> = c/(2·d<sub>max</sub>)，f<sub>high</sub> = c/(2·a)）、目标频段契合度、1D/2D 几何剖面，以及按井深聚合的裁切清单（体积与按密度估算的重量）。

> **说明**：有效频段为由几何尺度推算的估算值，**不含 BEM / FEM 物理仿真**，最终散射性能以现场测量或专业仿真为准。

### ㉚ 听觉与听阈（`#/hearing`）

> 听力计量侧：等响曲线、年龄相关听阈、听力图分级、临界带与掩蔽。与「心理声学 / 声品质」互补（那边管响度与粗糙度，这边管听阈与听力评价）。

- **ISO 226:2003 等响曲线**：phon ↔ dB SPL 双向换算。1 kHz 上 phon 数值恒等于 dB 数值；40 phon 时 100 Hz 需 64.4 dB、4 kHz 仅需 36.7 dB、8 kHz 需 51.8 dB。适用范围 20 Hz~12.5 kHz、20~90 phon（5 kHz 以上 20~80 phon），20 phon 以下仅具参考性；非表列频率按对数频率插值。附等响曲线族图（20/40/60/80 phon + 自由场听阈虚线）。
- **ISO 7029:2017 年龄相关听阈**：ΔH<sub>md,Y</sub> = α<sub>md</sub>·(Y−18)^β<sub>md</sub>（男女分列，125 Hz~8 kHz）。65 岁男性中位数阈移：1 kHz 约 10.4 dB、4 kHz 约 26.2 dB、8 kHz 约 39.5 dB；女性同岁 4 kHz 约 20.7 dB。3 kHz 以上且超过 70 岁的数值仅具参考性；公式上限 80 岁。
- **WHO 2021 听力图分级**：较好耳 500/1k/2k/4k 四频平均（PTA4，dB HL）→ <20 正常｜20~<35 轻度｜35~<50 中度｜50~<65 中重度｜65~<80 重度｜80~<95 极重度｜≥95 全聋；双耳输入，较好耳与较差耳分级并列，单侧损失（较好耳 <20 且较差耳 ≥35）单独标注。
- **RETSPL 听力零级**：ISO 389 / GB/T 4854.1（TDH-39 耳机 + IEC 303 耦合腔），1 kHz = 7.0、4 kHz = 9.5 dB SPL @ 0 dB HL，可把听力图 dB HL 折算为 dB SPL。
- **临界带与掩蔽**：Zwicker 刻度 z = 13·atan(0.00076f) + 3.5·atan((f/7500)²)、临界带宽 Δf = 25 + 75·(1 + 1.4(f/1000)²)^0.69（1 kHz 带 919~1081 Hz），附 Moore ERB 对照。掩蔽阈用简化扩散模型：带内平顶、带外按 Bark 距离线性衰减（下 −27 / 上 −20 dB/Bark，斜率可调），并给出扩散曲线图。

## 计算方法与公式

| 指标 | 方法 |
| --- | --- |
| A 声级 | L<sub>A</sub> = 10·log₁₀ Σ 10<sup>(Lᵢ + Aᵢ)/10</sup>，Aᵢ 取自 IEC 61672 |
| NC | 逐带对 NC 曲线表插值求指数，取各带最大值（ANSI/ASA S12.2 切线法） |
| NR | 逐带对 NR 曲线表插值求指数，取各带最大值（ISO/R 1996） |
| RC | RC = round(mean(L₅₀₀, L₁₀₀₀, L₂₀₀₀))；低频带(≤500 Hz)超参考曲线 >5 dB → R，高频带(≥2000 Hz) >3 dB → H，否则 N |

## 数据来源与精度说明

- **NC 曲线**：ANSI/ASA S12.2-2019（31.5 Hz 低频扩展列）+ 经典 Beranek/ASHRAE 曲线（63–8000 Hz，与 2019 版多数一致，个别如 NC-30@1kHz 差 1 dB）。NC 按切线法评估 31.5–8000 Hz 共 9 带；16 Hz 曲线列为推算值，仅用于低频一致性参考。
- **NC 低频一致性**：S12.2「频谱不平衡法」，以 NC(SIL) 曲线（SIL 取整到最近 5 dB 曲线）为基准。
- **NR 曲线**：ISO/R 1996 / BS EN 标准表（NR 0–130）。表中 62.5 Hz 列在本工具以 63 Hz 列近似（差值可忽略）。
- **A 计权**：IEC 61672 解析式（f₁=20.599、f₂=107.65、f₃=737.86、f₄=12194.2），与倍频带标准值差 <0.3 dB。
- **RC Mark II / QAI / RV**：ANSI/ASA S12.2-2019 Annex D；参考曲线为 1 kHz 锚点 −5 dB/倍频程直线，16/31.5 Hz 取 max(RC+25, 55)；QAI 与 RV 阈值按标准定义。
- **1/3 倍频程合成**：每倍频带取 f/√2 ~ f·√2 内的 1/3 带能量求和（16 Hz 带为 16/20 两条；12.5 Hz 未含于本工具频带表，对 16 Hz 带影响很小）。
- **QAI 解读**：标准未规定合格阈值；「≤5 dB 通常视为频谱均衡」为常用经验参考。
- **隔振计算**：《噪声与振动控制工程技术导则》第 7.4 节（无阻尼传递比 T = |1/(1−(f/f₀)²)|、频率比宜 2.5 ~ 4 且禁止 < 1.4、回转设备阻尼比宜 0.05 ~ 0.12、f₀ = 4.98·√(K_D/W)、动/静刚度比弹簧 1.0 / 橡胶 1.5 ~ 2.3）；含阻尼传递率与静变形法为通用隔振理论，频率系数取 √g/2π = 4.9840（g = 980.665 cm/s²），样本例题（234 kg / 1450 r/min / 4 只 / 3 kg/mm → f₀ ≈ 3.13 Hz、η ≈ 98.3%）已入测试断言核对。

## 部署到 Cloudflare

### 方式一：Worker + 连接 GitHub（推荐，推送即部署）

1. 在 Cloudflare 控制台 **Workers & Pages → Create → Worker → 从 Git 仓库导入**。
2. 选择你的 GitHub 仓库，分支默认 `main`，**构建命令留空**，**部署命令**保持默认 `npx wrangler deploy`。
3. 确认仓库根目录含有 `wrangler.toml`，其中 `name` 必须与 Cloudflare 里的 Worker 项目名**完全一致**（默认即 `acoustic-calc`，若你改名需同步改第一行 `name`）。
4. 推送代码到 `main`：Cloudflare 会自动克隆 → 安装 → `wrangler deploy`，把 `public/` 作为静态资源发布。
5. 部署完成后获得 `acoustic-calc.<你的子域>.workers.dev`，可在 **Settings → Domains** 绑定自有域名。

> 关键点：`wrangler.toml` 里 `[assets] directory = "./public"` 告诉 Wrangler 把 `public/` 当作站点根目录。若缺这一项或 `name` 不匹配，构建会失败（这正是之前报错的原因）。

### 方式二：Cloudflare Pages 直接上传（无需 GitHub / CLI）

1. 控制台 **Workers & Pages → Create → Pages → Upload assets（上传资源）**。
2. 把本仓库的 `public/` 文件夹拖入上传框（确保里面含 `index.html`）。
3. 完成后立即获得 `*.pages.dev` 链接，无需任何配置。

### 方式三：Wrangler CLI 手动部署

```bash
npm i -g wrangler
wrangler login
wrangler deploy          # 读取 wrangler.toml，将 public/ 作为资源发布
```
